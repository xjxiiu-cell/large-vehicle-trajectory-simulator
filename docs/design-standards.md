# 设计规范

## 色彩系统

### 主题色

基于 Ant Design 5 淡蓝色主题：

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#1677ff` | 按钮、链接、选中态 |
| 主色浅 | `#e6f4ff` | 悬浮态背景 |
| 背景 | `#f5f5f5` | 页面底色 |
| 面板背景 | `#ffffff` | 卡片/面板 |
| 成功 | `#52c41a` | 通行判定 |
| 错误 | `#ff4d4f` | 冲突区域 |
| 警告 | `#faad14` | 警告提示 |

### Canvas 画布颜色

| 图层 | 颜色 | 线宽 | 说明 |
|------|------|------|------|
| 网格 | `#e8e8e8` | 0.5px | 背景参考网格 |
| 道路中线 | `#1677ff` | 2px | 蓝色实线 |
| 道路边线 | `#52c41a` | 1.5px | 绿色虚线 |
| 扫掠包络线 | `rgba(22,119,255,0.3)` | - | 半透明蓝色填充 |
| 冲突区域 | `rgba(255,77,79,0.5)` | - | 半透明红色填充 |
| 车辆指示 | `#faad14` | 2px | 当前车辆位置 |

## 布局规范

### 面板尺寸

| 元素 | 宽度 | 说明 |
|------|------|------|
| 左侧面板 | 380px | 可折叠，最小 320px |
| 右侧画布 | flex: 1 | 填充剩余空间 |
| Tab 内容 | 100% | 面板内自适应 |

### 间距

- 面板内边距：16px
- 表单项间距：12px
- 卡片间距：16px
- Canvas 内边距：0（画布充满容器）

## 组件规范

### 表单

- 标签在左，输入框在右（水平布局），标签宽度 80px
- 数值输入使用 InputNumber，带单位后缀
- 选择项使用 Select 或 Radio.Group

### 表格

- 使用 Ant Design Table，斑马纹
- 数值列右对齐
- 单位在列标题中标注

### 按钮

- 主操作按钮使用主色（`type="primary"`）
- 导出按钮使用 `type="default"` + 下载图标
- 危险操作使用 `type="primary" danger`

## 轮子规范

- 错误提示使用 `message.error()`
- 成功提示使用 `message.success()`
- 加载状态使用 `Spin` 或 `Skeleton`
- 确认操作使用 `Modal.confirm()`

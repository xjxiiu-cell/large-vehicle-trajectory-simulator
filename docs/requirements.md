# 需求文档

## 项目概述

大型车辆行驶轨迹模拟软件，运行于网页端，服务于风力发电道路设计。模拟 20-40 米超长运输车辆在 5km/h 低速下的行驶轨迹，辅助判断现有道路能否满足通行要求。

## 功能需求

### 1. 车辆参数输入

用户手动输入车辆尺寸与配置，系统根据车辆类型采用不同计算方案：

| 参数 | 说明 |
|------|------|
| 车辆类型 | 单体车（刚性车身）/ 牵引车+挂车（铰接式） |
| 总长度 | 20-40 米 |
| 总宽度 | 用户输入（米） |
| 轮轴配置 | 轴数、各轴距前端的距离 |
| 转向方式 | 前轮转向 / 全轮转向（单体车） |
| 铰接点位置 | 仅铰接车，牵引车与挂车连接点距牵引车后轴的距离 |

### 2. CAD 道路导入

- 支持格式：DWG（AutoCAD 2012-2022）、DXF 备用
- 道路数据分为两个图层：道路中线、道路边线
- 用户导入后浏览器内可视化展示
- 用户指定中线/边线图层的对应关系

### 3. 轨迹模拟计算

- 刚性车以 5 km/h 匀速前进；系统以**最后轴中心、车身朝向和实际转向角**作为连续运动学状态，在道路横向可用范围内自动规划路线
- 紫色线表示由连续状态推导出的前转向轴实际轨迹；青色线表示后轴实际轨迹。车辆轮廓、扫掠包络和碰撞结果全部由同一组后轴连续状态生成
- 路线须满足用户设定的单侧安全净距（当前默认 0.5m），并检查完整车身轮廓不与道路边线相交
- 找不到连续安全路线时，明确给出不可通行结论及对应里程，而非强制沿中线行驶
- 计算扫掠包络线（车辆轮廓在全程扫过的区域）
- 判断包络线是否完全在道路边线以内
- 超出边线的冲突区域用红色高亮标记
- 长道路计算在后台执行，界面显示规划/复核进度，并允许用户取消本次计算

#### 3.1 单半挂车（V2）

- 支持“前轮转向牵引车 + 单半挂车”的**前进行驶**；当前只支持固定挂车等效轴组。
- 用户分别输入牵引车、第五轮、半挂车尺寸与轴配置；挂车前后尺寸以“牵引销→前端、牵引销→等效轴组、等效轴组→车尾”定义。
- 牵引车最后轴、车身朝向、挂车朝向和实际前轮转角构成连续状态；第五轮与挂车等效轴组由几何约束实时推导，不允许挂车独立跳变。
- 自动路线同时校核牵引车与半挂车完整车身、单侧安全净距及转向连续性；无解时仅显示最远真实可执行的前进轨迹，并注明首个问题车体。
- 画布分别显示：牵引车扫掠（蓝）、半挂车扫掠（粉红）、当前半挂车车身（紫）、牵引车问题（红色 X）与半挂车问题（紫色 X）。
- 被动/主动可转向挂车轴须以厂家转向规律或实测标定接入；没有资料时不得用固定轴结果替代该车型的工程结论。

### 4. 转弯半径-道路宽度计算表

- 系统根据车辆参数自动计算最小转弯半径
- 用户输入最大半径
- 生成半径列表：最小值 → 向上取整到 5 的倍数 → 每 5m 递增 → 最大半径
- 计算每个半径对应的所需最小道路宽度
- 以表格形式展示

### 5. 结果导出

- 导出扫掠包络线为 DWG（或 DXF）格式
- 可导入回 AutoCAD 叠加查看

### 6. 界面要求

- 简洁直观，适合非技术人员
- 淡蓝色主题
- 左侧参数面板 + 右侧图形画布布局

## 非功能需求

- 纯前端应用，浏览器直接运行
- 支持 Chrome、Edge、Firefox 现代浏览器
- 预留三维（高程/坡度）扩展接口

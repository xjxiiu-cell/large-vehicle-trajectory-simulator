# V2 铰接车轨迹模拟：开发与对接计划

> 版本：V2.0（计划）  
> 创建日期：2026-09-18  
> 当前状态：V2-4 已由用户确认验收；V2-1A 按用户要求暂缓，待后续取得目标车型资料后恢复  
> 推进规则：每个阶段完成后必须停止，由用户使用实际图纸测试并明确发出下一阶段启动指令。

## 1. 目标与边界

V2 为现有网页端大型车辆轨迹模拟系统增加**前轮转向牵引车 + 单半挂车**的低速轨迹模拟能力。

本轮固定约束：

- 只支持前进行驶，默认速度 5km/h。
- 内部单位统一为米；车辆参数、CAD 道路和安全净距均以米计算。
- V2 基础车型为固定挂车轴组；可转向挂车轴另列 V2-1A，默认不启用。
- 所有结果均为“几何模拟结果”，在实车或厂家扫掠资料交叉验证前，不作为最终工程设计结论。

本轮不包含：倒车、多挂车、可独立规划的主动挂车转向、轮胎动力学/磨耗、坡度与三维动力学、DXF 导出。

## 2. 已确认的产品约定

| 项目 | 约定 |
| --- | --- |
| 车型 | 前轮转向牵引车 + 单半挂车 |
| 行驶方向 | 只前进 |
| 参数输入 | 延续刚性车的“尺寸 + 轴配置”方式；牵引车和挂车均独立填写 |
| 牵引车参考 | 牵引车最后轴中心是连续积分的内部参考点 |
| 前轴紫线 | 牵引车前转向轴的实际轨迹，由连续状态推导 |
| 挂车参考 | 挂车等效后轴组中心由铰接点几何约束实时推导，禁止独立累积位置 |
| 安全规则 | 牵引车和挂车任一车身不满足边界或净距要求，即判为问题 |

## 3. 关键模型定义

### 3.1 坐标、符号与几何约束

```text
前进方向 →
牵引车前转向轴 ── L ── 牵引车后轴 R ── a ── 铰接点 H ── b ── 挂车等效后轴组中心 T
```

- `R = (x, y)`：牵引车最后轴中心。
- `θ`：牵引车朝向；`ψ`：挂车朝向。
- `δf`：牵引车等效前轮转角；`L`：牵引车前后轴距。
- `a`：牵引车后轴至第五轮的有符号距离。第五轮位于后轴后方时为负值。
- `b`：第五轮至挂车等效后轴组中心的距离，恒为正值。
- `α = wrap(θ - ψ)`：铰接角，正负方向必须保留。

每帧均按以下约束重建铰接点和挂车轴组，禁止对挂车轴位置单独累积：

```text
H = R + a · (cos θ, sin θ)
T = H - b · (cos ψ, sin ψ)
```

### 3.2 固定挂车轴连续状态

```ts
interface ArticulatedVehicleState {
  tractorRearAxle: Point2D;
  tractorHeading: number;
  trailerHeading: number;
  steeringAngle: number;
  station: number;
}
```

按 `ds ≤ 0.1m` 前进积分。牵引车沿已验证的自行车模型推进；挂车朝向按无侧滑半挂车方程连续更新，再由上节的几何约束求出 `H` 与 `T`。牵引车转向角继续受 `maxSteeringRateDegPerSec` 限制。

### 3.3 挂车后部可转向轴

挂车后部“可转向”不是单一功能，接口必须区分：

```ts
type TrailerAxleSteeringMode =
  | 'fixed'
  | 'passive_linked'
  | 'active_linked'
  | 'active_commanded';

interface TrailerSteeringParams {
  mode: TrailerAxleSteeringMode;
  equivalentAxleGroupCenterFromHitchM: number;
  maxSteeringAngleDeg?: number;
  maxSteeringRateDegPerSec?: number;
  steeringLaw?: {
    articulationGain?: number;
    tractorSteeringGain?: number;
    deadbandDeg?: number;
    centerReturnRateDegPerSec?: number;
  };
  axleRows?: Array<{ offsetFromHitchM: number; steerable: boolean }>;
}
```

`passive_linked`、`active_linked` 与 `active_commanded` 需要厂家曲线、实测标定或控制规律。没有这些数据时，只能使用 `fixed`；界面必须提示“未按该车型转向机构标定”。

## 4. 分阶段实施计划

### V2-1：固定挂车轴连续运动学与显示

启动指令：`开始 V2-1`

实施内容：

- 完善牵引车和挂车的尺寸、前后悬、轴配置、第五轮位置及挂车等效轴组位置输入与校验。
- 新增 `ArticulatedVehicleState`、铰接几何和纯函数积分器。
- 新增牵引车矩形、挂车矩形、铰接点、牵引车前轴紫线、牵引车后轴线、挂车后轴线与当前三点标记。
- 回放步骤输出牵引车/挂车角点、铰接点、铰接角及实际转向角。
- 挂车轴组转向类型可选择，但 V2-1 仅允许 `fixed`；其他类型显示数据要求，不参与模拟。
- 补齐单元测试：直行、恒定转角圆弧、铰接约束、内轮差、转向角速率、相邻状态连续。

验收并停止：

- 用户用直线、左弯、右弯图纸回放，确认挂车后轴连续、向弯内侧合理偏移，铰接点不脱开。
- `npm run test` 与生产构建通过。
- 未验收前，不进入 V2-1A、V2-2 或 V2-3。

### V2-1A：一个等效可转向挂车轴组（可选）

启动条件：V2-1 已验收，且已取得目标车型的转向机构资料。

启动指令：`开始 V2-1A`

实施内容：

- 只支持一个等效可转向轴组，不实现多根轴各自的 Ackermann 轮胎模型。
- 根据车型选择被动随动或主动联动；录入最大角度、角速度、死区、回正、锁止条件及厂家/实测转向曲线。
- 增加挂车等效轴转角状态与连续积分；画布显示其轨迹和转向方向。
- 以厂家扫掠图或实车轨迹验证转向方向、回正趋势和内轮差变化。

验收并停止：

- 用户确认该车型在直线、左右弯中挂车轴的转向方向与实际一致。
- 没有车型资料时，本阶段不启动，V2 继续按固定轴组模拟。

### V2-2：双车身安全走廊、冲突和扫掠

启动条件：V2-1 已验收；若目标车型使用可转向轴，则 V2-1A 也已验收。

启动指令：`开始 V2-2`

实施内容：

- 将安全走廊检查从单矩形扩展为牵引车与挂车两个完整车身矩形。
- 每个 0.1m 子步计算两车身的边界碰撞、最小净距和道路外越界。
- 冲突结果新增车体归属：`tractor` / `trailer`，并记录里程、净距、角点/边及原因。
- 分别为牵引车和挂车生成相邻轮廓扫掠片段，画布用不同视觉标识显示。
- 回放时高亮发生问题的具体车体。

实现记录（2026-09-18）：

- 已按 0.1m 连续状态分别复核牵引车和半挂车完整车身；每个冲突记录 `tractor` / `trailer` 归属、里程、净距和原因。
- 已分别生成牵引车蓝色、半挂车紫色的连续扫掠片段；不再将两个车身跨帧直接连成单一扇形。
- 回放时本步发生问题的车身以红色高亮；冲突标记以红色表示牵引车、紫色表示半挂车。
- 当前仍是“中线引导下的双车身安全复核”，不等同于自动安全选线；Hybrid A* 铰接车规划仍属于 V2-3。

验收并停止：

- 以同一图纸分别设定 0m、0.5m、1m 安全净距，确认结果随净距增加而收紧。
- 确认冲突点贴合实际靠近边线的牵引车或挂车轮廓。

### V2-3：铰接车自动安全路线

启动条件：V2-2 已验收。

启动指令：`开始 V2-3`

实施内容：

- 扩展现有 Hybrid A* 状态为牵引车后轴位置、牵引车朝向、挂车朝向、牵引车转向角和道路进度。
- 固定挂车轴或已定义联动规律的可转向轴，均由连续积分产生；规划器不得将挂车贴线或瞬移。
- 每个原语前进 0.5m，内部按 0.1m 进行双车身安全校验；保持只前进、Worker 计算、进度和取消。
- 路线排序：最大化全程最小净距 → 最小化牵引车转向/转向变化 → 最小化铰接角/铰接角变化 → 减少牵引车前轴对道路引导线的偏移。
- 无解时仅返回最远连续可执行轨迹，并明确是牵引车冲突、挂车冲突、净距不足、铰接角限制或道路数据异常。

实现记录（2026-09-18）：

- 已新增前进式铰接车 Hybrid A*：搜索状态为牵引车后轴、牵引车朝向、挂车朝向和实际前轮转角；每个候选动作前进 0.5m，内部固定按 0.1m 连续积分。
- 每个子步均复核牵引车和半挂车完整轮廓；规划状态去重同时考虑横向偏移、牵引车朝向误差、铰接角和实际转角。
- 评分顺序为全程最小净距优先，其次转向平顺、道路跟踪、铰接角及其变化；道路中线只作引导，不再直接决定车辆位置。
- 无解时返回最远已验证状态和首个失败车体/冲突，不生成后续中线伪轨迹；Worker 保持进度与取消能力。
- V2-3 验收中发现弯道前中途停止的假无解风险：波束搜索现保留左转、直行、右转三类安全候选，并将前瞻距离提高至至少一个挂车轴组尺度；未降低边线或净距约束。

验收并停止：

- 用户确认车辆在进入弯道前的调整连续；牵引车与挂车轨迹符合内轮差规律。
- 在可通过和不可通过道路上分别确认净距优先和最远连续部分轨迹。

### V2-4：交付验证与文档同步

启动条件：V2-3 已验收。

启动指令：`开始 V2-4`

实施内容：

- 对真实 DXF/DWG 的直线、左右圆弧、bulge 圆弧、不同导入方向和窄路场景回归。
- 增加性能测试、大图纸提示和取消计算验证；生产构建验证。
- 完善需求、技术规格、执行步骤和开发日志；将已确认的车型约束写入正式规格。

实现记录（2026-09-18）：

- 已新增半挂车直线入弯性能回归，覆盖自动路线、双车身净距校核与扫掠生成；本机基准要求 5 秒内完成。
- 已复核模拟运行在 Web Worker；界面保留进度并可直接终止 Worker 取消计算，避免长道路计算阻塞页面。
- 已在模拟面板明确显示“几何模拟结果”提示；牵引车/挂车扫掠、当前车身和冲突归属保持可区分颜色。
- 已同步需求文档、技术规格、执行步骤和开发日志；真实 DWG/DXF 的最终复核仍必须由用户完成。
- 2026-09-18：用户已确认 V2-4 验收。固定挂车轴的 V2 交付闭环；后续可在取得目标车型转向机构资料后启动 V2-1A。

验收并停止：

- 实际图纸与车型尺寸下，车辆、扫掠、冲突和道路可准确叠加。
- 界面保留“几何模拟结果”提示，直至与厂家扫掠图或实车资料完成交叉验证。

## 5. 对接资料清单

### V2-1 必需资料

- 牵引车：总长、总宽、前悬、后悬、各轴距车头距离、轮距、前转向轴最大角与角速度。
- 第五轮：相对牵引车最后轴的前后位置，明确是在后轴前方还是后方。
- 挂车：总长、总宽、前悬、后悬、各轴相对第五轮的位置、挂车等效轴组中心。
- 道路：包含中线、左边线、右边线的米制 DXF/DWG；推荐三图层模式。

### V2-1A 额外资料

- 挂车后部轴组的转向类别：固定、被动随动、液压/电控主动联动或人工独立控制。
- 哪些轴可转向、轴距和相对第五轮位置。
- 最大转角、最大角速度、直行回正、低速/倒车锁止和死区规则。
- 厂家 `δt–α` 或 `δt–δf` 曲线、扫掠模板，或至少一段可标定的实车前进行驶轨迹。

## 关键算法

### 后轴连续状态 + Ackermann 转向几何（刚性车）

用于计算前轮转向车辆的瞬时运动轨迹：

- 瞬时旋转中心 (ICR) 位于后轴延长线上
- 内侧前轮转角 δ_inner > 外侧前轮转角 δ_outer
- 最小转弯半径：R_min = W/2 + L / tan(δ_max)
- `RigidVehicleState` 是唯一状态源：最后轴中心、车身朝向、实际前轮转角和行驶里程。`VehiclePose.position` 始终表示最后轴中心。
- 以自行车模型积分：\(dθ/ds=tan(δ)/L\)。每个 0.1m 子步根据车速和 `maxSteeringRateDegPerSec` 限制转向角变化，再推进后轴；前转向轴位置由轴距和当前车身朝向正向推导，绝不由紫线反推后轴。
- 当前默认车速为 5km/h、转向角变化率为 10°/s。紫色和青色轨迹、车辆回放、扫掠和冲突判定都来自同一连续状态序列。

### 铰接车连续运动学（V2）

V2 固定为前轮转向牵引车 + 单半挂车、只前进、固定挂车等效轴组。内部唯一状态为：

```ts
interface ArticulatedVehicleState {
  tractorRearAxle: Point2D;
  tractorHeading: number;
  trailerHeading: number;
  steeringAngle: number;
  station: number;
}
```

每个子步 `ds ≤ 0.1m`，牵引车按已验证的自行车模型与转向角速度限制积分；挂车朝向连续更新。第五轮和挂车等效轴组不存储独立位置，而是每帧重建：

```text
H = R + a · (cos θ, sin θ)
T = H - b · (cos ψ, sin ψ)
```

其中 `R` 为牵引车最后轴中心、`H` 为第五轮、`T` 为挂车等效轴组中心、`a` 为最后轴到第五轮的有符号距离、`b` 为第五轮到等效轴组距离。该约束避免前轴路线正确而挂车/后轴在相邻帧漂移。

铰接车 Hybrid A* 搜索状态为 `R, θ, ψ, δf` 和道路进度；每个 0.5m 原语内部拆成 0.1m 双车身校核。状态去重包含横向偏移、牵引车朝向、铰接角与实际转角；波束搜索保留左转、直行、右转候选，以免进弯前的必要调整被过早淘汰。排序依次为：全程最小净距、转向平顺、道路跟踪、铰接角及其变化。

固定轴之外的被动随动、主动联动和主动控制挂车轴必须有厂家转向曲线或实测标定；接口已预留，但 V2 不参与计算。

### 扫掠包络线

每两个相邻车辆轮廓组成一个连续扫掠片段。画布逐片渲染，避免跨越弯道首尾的直连线形成虚假的红色扇形；碰撞结论仍以每个 0.1m 子步的完整车身轮廓精确复核。

铰接车将牵引车和半挂车分别形成连续扫掠片段：牵引车为蓝色、半挂车为粉红色；当前回放的半挂车车身保持紫色，以与扫掠区分。

### 碰撞检测

道路边线先构成安全走廊：统一左右边线方向，拒绝断开、退化或相交边线。每个车辆轮廓必须位于走廊内，且到任一侧边线的距离不小于设定净距；结果区分边界碰撞、净距不足和道路导入异常。

自动路线采用只前进的 Hybrid A*。搜索状态为后轴位置、朝向和实际转向角；每个动作前进 0.5m，并在内部以 0.1m 连续积分和完整车身校核。动作覆盖最大转角范围内的 9 档目标值，实际转角仍受速率限制。排序依次为最大化全程最小净距、最小化转向/转向变化、最小化中线偏离。无解时只输出最远连续可执行部分和首次问题位置。

规划阶段对道路边线使用 5m 空间网格索引，仅检查车辆附近边线；最终模拟仍使用全量精确校核。计算通过 Web Worker 执行，按规划 80% / 逐帧复核 20% 回传进度，可随时终止。

## 3D 预留接口

- Point2D 携带可选 `z: number` 字段，当前默认为 0
- VehicleParams 预留 `clearance`（离地间隙）、`tireRadius`（轮胎半径）
- RoadGeometry 预留 `elevationProfile`（高程剖面）
- 模拟函数接受可选 `slope` 参数
